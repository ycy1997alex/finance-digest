# finance-digest

台灣財經 YouTube 節目的每日摘要網站：https://ycy1997alex.github.io/finance-digest/

每個交易日晚上，網站會整理當天約十支財經節目影片裡分析師講了什麼，週日另出一份週末版。週六和證交所休市日不出刊，那幾天的節目併進下一份。

這個 repo 只放網站本身（`docs/`），內容全部加密，要輸入密碼才看得到；搜尋引擎也不會收錄。產生網站的程式不在這裡。

## 網站上有什麼

**今日**：最新一期的報告，可以用上方的日期列切換到前後幾期。一期分成幾個段落：

- 今日焦點：當天最重要的幾件事
- 總體經濟與市場環境：每一點都標出是哪位分析師說的
- 多空共識：兩位以上分析師看法同方向的產業與個股
- 主要分歧：分析師意見相反的題目，多方、空方並列
- 分析師重點：每位分析師的主題、市場看法、投資策略、看好與看壞的產業、提到的個股；可以切換成卡片或表格
- 影片來源：每支影片的頻道、標題、上架時間和長度，點了直接開 YouTube

頁首會寫這一期涵蓋的時間範圍和產生時間。重新發布過的期別會多一行「更新於」，寫出日期與時間。有節目沒讀到時，會在最上面列出缺了哪幾個。

**封存**：以月曆列出每一期，點日期就打開當天的報告。

**追蹤**：統計最近 30 天的資料。

- 搜尋股名、股票代號或分析師
- 熱門個股：依被提及次數排名，附看多、中性、看空的比例。預設顯示前 10 名，按「顯示更多」可以在清單裡往下捲，看完全部
- 分析師：每位分析師最近 10 期的態度；點進去看這位分析師的歷次觀點
- 每檔個股也有自己的頁面，列出誰在哪一天提過、看多還是看空

**其他**

- 「複製 LINE 版」：把當期整理成精簡的文字，直接貼到 LINE
- 「複製這一期的連結」：每一期都有固定網址 `…/finance-digest/YYYY-MM-DD/`
- 閱讀設定：字級（標準、大、特大）、配色（跟隨系統、淺色、深色）；電腦上還能切換滿版寬度。這些設定只存在你自己的瀏覽器裡
- 鎖定：離開前按右上角的鎖，這個分頁就要重新輸入密碼

## 注意

網站內容由 AI 依節目內容自動整理，只轉述節目中講者的觀點，不代表本站立場，也不構成任何投資建議。股票代號經臺灣證券交易所 ISIN 清單比對，比對不到的會標「代號待確認」。
